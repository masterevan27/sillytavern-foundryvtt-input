This is the SillyTavern UI half of the NHP Uplink, published on its own
so SillyTavern's extension installer can reach it. On its own it does
nothing.

## Install

In SillyTavern, go to **Extensions -> Install extension** and paste:

```
https://github.com/masterevan27/sillytavern-foundryvtt-input
```

Then follow the full setup at <https://github.com/masterevan27/foundryvtt-to-sillytavern-nhp-uplink#install>. You also need the
Foundry module and the SillyTavern **server plugin** -- the server plugin
is what this extension actually talks to.
